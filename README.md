# Retail Sales Analysis 📊

## 📌 Project Overview

This project focuses on analyzing retail sales transactions from 2024–2025 using Python. It covers data cleaning, exploratory data analysis (EDA), feature engineering, data visualization, regression analysis, and classification models to understand sales patterns and evaluate machine learning techniques.

The project uses a retail sales dataset containing 500 transactions with information about products, quantities, unit prices, discounts, sales channels, regions, and order dates.

## 🎯 Objectives

- Clean and preprocess retail sales data.
- Handle missing values and duplicate records.
- Perform exploratory data analysis to identify sales patterns.
- Create meaningful features from existing data.
- Detect potential outliers using statistical methods.
- Apply categorical encoding and numerical scaling.
- Implement and evaluate regression models.
- Compare classification algorithms for sales prediction.
- Visualize important insights and model performance.

## 🛠️ Technologies Used

- **Python**
- **Jupyter Notebook**
- **Pandas** – Data manipulation and analysis
- **NumPy** – Numerical computations
- **Matplotlib** – Data visualization
- **Seaborn** – Statistical visualization
- **Scikit-learn** – Machine learning and preprocessing
- **SciPy** – Statistical analysis
